# TranslateGemma on Google Colab for TransLLM + Trados Studio

Connect Trados Studio to TranslateGemma running on Google Colab using TransLLM, Ollama, FastAPI, and ngrok.

Run TranslateGemma through Ollama on a Google Colab GPU and connect it remotely to Trados Studio using TransLLM.


[Open in Google Colab]

## What this notebook does

Trados Studio
-> TransLLM
-> ngrok
-> FastAPI proxy
-> Ollama
-> TranslateGemma

## Requirements

- Trados Studio
- TransLLM
- Google account
- ngrok account
- Internet connection
